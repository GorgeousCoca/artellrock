# Какой MCP-инструмент когда использовать

Три помощника для работы с сайтом. Выбираем по задаче, а не по привычке.

| Инструмент | Роль | Простыми словами |
|---|---|---|
| **Sitemap MCP** | Разведчик (Картограф) | Показывает карту сайта: какие страницы есть, когда обновлялись, как разделы вложены друг в друга. |
| **Firecrawl MCP** | Экстрактор (Сборщик контента) | Забирает со страницы чистый текст или таблицу, без меню, рекламы и кода. |
| **Puppeteer MCP** | Глаза и Руки (Тестировщик) | Открывает настоящий браузер: нажимает кнопки, вводит числа, делает скриншоты, проверяет мобильный вид. |

## Что умеет и чего не умеет

### Sitemap MCP
- **Умеет:** дерево всех ссылок из `sitemap.xml`, дата обновления, вложенность, статистика.
- **Не умеет:** читать текст внутри страниц, видеть дизайн.
- Инструменты: `get_sitemap_tree`, `get_sitemap_pages`, `get_sitemap_stats`, `parse_sitemap_content`.

### Firecrawl MCP
- **Умеет:** превращать страницы в Markdown или JSON, вырезать лишнее (экономит до 80% ресурсов ИИ), собирать сразу много страниц.
- **Не умеет:** кликать по сложным элементам (калькуляторы, всплывающие окна), видеть визуальный дизайн.
- Нужен ключ `FIRECRAWL_API_KEY` в настройках MCP.
- Главные инструменты: `firecrawl_scrape` (одна страница), `firecrawl_crawl` (много страниц), `firecrawl_map` (список адресов), `firecrawl_search` (поиск в интернете).

### Puppeteer MCP
- **Умеет:** скриншоты, клики, выбор фильтров, ввод чисел, проверка мобильной вёрстки.
- **Не умеет:** быстро обходить сотни страниц (медленно, это не его задача).
- Инструменты: `puppeteer_navigate`, `puppeteer_click`, `puppeteer_fill`, `puppeteer_select`, `puppeteer_hover`, `puppeteer_screenshot`, `puppeteer_evaluate`.

## Шпаргалка: задача, инструмент

| Задача | Берём |
|---|---|
| Сколько страниц на сайте, нет ли лишних или пропавших | Sitemap |
| Проверить, что новые страницы каталога попали в `sitemap.xml` | Sitemap |
| Свежесть страниц (поле `lastmod`) | Sitemap |
| Забрать тексты конкурентов для сравнения | Firecrawl |
| Выгрузить таблицу цен или характеристик с чужой страницы | Firecrawl |
| Прочитать текст своих страниц для SEO-аудита | Firecrawl |
| Проверить, что калькулятор считает цену | Puppeteer |
| Прокликать каталог: фильтры, карточки камней, формы заявок | Puppeteer |
| Скриншот страницы на телефоне и на компьютере | Puppeteer |
| Проверить, что вёрстка не поехала после рефакторинга | Puppeteer |

## Типовой порядок работы

1. **Sitemap.** Получаем список страниц сайта.
2. **Firecrawl.** По списку забираем текст нужных страниц, например для SEO.
3. **Puppeteer.** Проверяем то, что нужно «потрогать»: калькулятор, формы, телефон.

## Для этого проекта

- **После рефакторинга каталога (`/catalog-kvarca`).**
  - Puppeteer открывает бренд и карточку камня, проверяет цены и картинки.
  - Sitemap сверяет, что все страницы камней на месте.
- **Калькулятор (`/kalkulyator`).** Только Puppeteer: ввод размеров, выбор камня, отправка заявки.
- **SEO.** Sitemap даёт список страниц, Firecrawl даёт тексты для анализа заголовков и описаний.
- **Конкуренты (Евро-камень, Экостоун и др.).** Sitemap находит разделы, Firecrawl собирает цены и тексты.

## Правила безопасности

- Puppeteer и Firecrawl по умолчанию работают с локальным сайтом (`http://localhost:3000`) или с публичными страницами.
- Не отправлять настоящие заявки в Puppeteer-тестах на боевом сайте. Использовать локальный сервер или тестовые данные.
- Ключи (`FIRECRAWL_API_KEY` и др.) не записывать в проект и не коммитить.
